# 单页促销文案排查 · 使用说明

广告组、店铺组共用。系统自动进结账页，识别套餐售价下方的促销文案，并按现价/划线价测算是否对得上。测算过仍需人工扫一眼；包邮等纯文案必须进店核对。

工具地址：（部署完成后把 Streamlit 网址填在这里）

---

## 1. 打开哪个网址

用浏览器打开上方工具地址即可，不用装 Python。  
广告组、店铺组都用这一个入口。

---

## 2. 怎么提交链接

两种方式都能跑，也可以一起用（重复链接会去重）。

**上传 Excel（一批排查）**

- 下载页面上的链接模板，或用现有表
- **第一列放单页链接**（落地页、结账页都可以；有没有 `https://` 都行）
- 上传 `.xlsx` 后点「开始排查」

**粘贴链接（抽查 1～2 条）**

- 在粘贴框里一行一条
- 逗号分隔也可以
- 点「开始排查」

建议每批不超过 80 条，太多时云上会比较慢。

---

## 3. 看哪两列

结果表里重点看：

| 列 | 含义 |
| --- | --- |
| 系统检查结果 | 系统按价格算出来的结论 |
| 是否人工复核 | 要不要人再看一眼 |

同时会列出：类型、促销文案原文、测算说明、结账页链接。

**类型**只会是下面这些，**不会出现「无需整改」**：

- 无促销文案
- 促销文案含价格（如 `only $8.62 each!`、`$38.99/set`）
- 促销文案为纯折扣（如 `50% OFF`）
- 促销文案含价格与折扣（如 `50% OFF $46.5/each`）
- 纯文案（如包邮，不是折扣也不是每件价）

---

## 4. 结果怎么处理

| 系统检查结果 | 是否人工复核 | 你要做什么 |
| --- | --- | --- |
| 无促销文案 | 否 | 一般可过 |
| 测算一致 | 是 | 价格对得上，仍请打开结账页扫一眼展示是否正常 |
| 测算不符 | 是 | 文案和现价/划线价对不上，优先整改 |
| 纯文案，无法按价格测算 | 是 | 多为包邮等。系统进不了店铺，必须进店核对运费/包邮条件 |
| 无法完整测算 / 无法检测 | 是 | 打不开结账页，或件数/划线价缺了，需人工点开看 |

说明：

- 系统查的是结账页**套餐红色现价下面那一行**，不是顶栏，也不是 `$68.99` 现价本身。
- `only $X each`：现价 ÷ 件数；`$X/set`：现价 ÷ 套数；`N% OFF`：相对划线价。
- 折扣允许大约 ±2.5 个百分点（例如约 48%～50% 写成 50% OFF 可算测算一致）；金额允许差约 0.02 美元。

---

## 5. 不要用这个工具做什么

- 不代替人工终审。有促销文案时，即使测算一致也建议扫一眼。
- 不核对店铺后台的包邮门槛、运费模板、活动是否真实开启。
- Banner 如果是纯图、没有这行文字，系统读不到。
