# 单页促销文案排查 · 使用说明

广告组、店铺组共用。系统自动进结账页，识别价下方、规格名称、规格标签和顶栏里的促销文案，并按现价/划线价测算是否对得上。套餐卡和 SKU 新布局都能查。测算过仍需人工扫一眼；包邮等纯文案必须进店核对。

工具地址：（部署完成后把 Streamlit 网址填在这里）

---

## 1. 打开哪个网址

用浏览器打开上方工具地址即可，不用装 Python。  
广告组、店铺组都用这一个入口。

---

## 2. 怎么提交链接

两种方式都能跑，也可以一起用（重复链接会去重）。

**上传 Excel（一批排查）**

- 下载页面上的链接模板，或用现有表
- **第一列放单页链接**（落地页、结账页都可以；有没有 `https://` 都行）
- 上传 `.xlsx` 后点「开始排查」

**粘贴链接（抽查 1～2 条）**

- 在粘贴框里一行一条
- 逗号分隔也可以
- 点「开始排查」

建议每批不超过 80 条，太多时云上会比较慢。

---

## 3. 看哪两列

结果表里重点看：

| 列 | 含义 |
| --- | --- |
| 系统检查结果 | 系统按价格算出来的结论 |
| 是否人工复核 | 要不要人再看一眼 |

同时会列出：类型、促销文案原文、测算说明、结账页链接。

**类型**只会是下面这些，**不会出现「无需整改」**：

- 无促销文案
- 促销文案含价格（如 `only $8.62 each!`、`$38.99/set`）
- 促销文案为纯折扣（如 `50% OFF`）
- 促销文案含价格与折扣（如 `50% OFF $46.5/each`）
- 纯文案（如包邮，不是折扣也不是每件价）

---

## 4. 结果怎么处理

| 系统检查结果 | 含包邮 | 你要做什么 |
| --- | --- | --- |
| 无促销文案 | 否 | 一般可过 |
| 测算一致 | 否 | 价格对得上，仍请打开结账页扫一眼 |
| 测算一致 | 是 | 折扣/单价对得上；包邮须进店核对运费 |
| 测算不符 | 是/否 | 文案和价格对不上，优先整改（有包邮也先改折扣） |
| 纯文案，无法按价格测算 | 是 | 只有包邮等，没有可测算的折扣/单价，必须进店核对 |
| 无法完整测算 / 无法检测 | — | 打不开结账页，或件数/划线价缺了，需人工点开看 |

说明：

- 系统会查这些位置，结果表「出现位置」「促销文案」会分开列出（不是 `$68.99` 现价本身）：
  - 价下方：套餐红色现价下面那一行（如 `only $8.62 each!`）
  - 规格名：规格名称里的折扣（如 `(Save 32% OFF)`）
  - 规格标签：标签上的价格促销（如写 `50% OFF`；纯 `Best Seller` 不算）
  - 顶栏：倒计时/促销条（如 `get 50% OFF`）。顶栏会测算并写在说明里；有价下方/规格文案时，顶栏不对整页一票否决。
- SKU 新布局按规格 ID 对齐价格，避免推荐套餐排在最前时算错。
- `only $X each`：现价 ÷ 件数；`$X/set`：现价 ÷ 套数。
- 价下方 / 顶栏 / 标签的 `N% OFF`：相对划线价，`(划线价 - 现价) ÷ 划线价`。
- 规格名称里的 `Save N%` / `N% OFF`：相对**单独买这些规格的现价合计**，例如猫+狗+幽灵+圣诞 = `$16.99×4`，再和套餐现价比。不是划线价。
- 折扣**按小数点后第一位四舍五入**（只看十分位：0–4 舍、5–9 入，第二位不进位）。例如 32.90% 应写 `33% OFF`，49.45% 应写 `49% OFF`。不设容差区间。金额允许差约 0.02 美元。

---

## 5. 不要用这个工具做什么

- 不代替人工终审。有促销文案时，即使测算一致也建议扫一眼。
- 不核对店铺后台的包邮门槛、运费模板、活动是否真实开启。
- Banner 如果是纯图、没有这行文字，系统读不到。
